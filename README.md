# InvolveX Skills

A collection of Claude Code skills for web and mobile development, featuring specialized workflows for React, Cloudflare Workers, Expo, Capacitor, AI agents, and more.

## Installation

```bash
npx skills add involvex/skills
```

## Usage

Skills are automatically loaded when a matching task is detected. You can also manually load a skill:

```
Load the cloudflare skill for Workers development
```

Skills include detailed references in their `references/` subdirectories with deeper documentation on specific topics.

## Contributing

Follow the `skill-creator` skill guidelines when adding new skills. Skills must include:

- `SKILL.md` with name, description, and instructions
- Proper metadata header
- References subdirectory for detailed docs if needed
